# Product Roadmap — Simone Cloud

| Stage | Feature Area | Status | Description |
| :--- | :--- | :--- | :--- |
| **1. MVP** | Single host management, VM CRUD & lifecycle (Start, Stop, Reboot, Delete), private/NAT networking, mobile dashboard, job tracking, audit logs | **Working** | Core control plane for private cloud VPS management. |
| **2. Operations** | Multi-host clusters, host maintenance mode, snapshots, backups, hypervisor telemetry | **Planned** | Advanced enterprise infrastructure operations. |
| **3. Networking** | Public IP allocation, custom firewall rule builder, VPC peering, DNS integration | **Planned** | Customer-controlled virtual networking. |
| **4. Platform** | Multi-tenant RBAC, quotas, API keys, usage metering, and team management | **Planned** | Enterprise organization management and billing. |
